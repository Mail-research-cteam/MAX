# MAX

# Shared Access Research Prototype

Прототипы для UX-исследования нового сценария совместной работы с почтовым ящиком Mail.

Исследование проверяет, насколько пользователям понятна модель доступа к общему ящику:
- как владелец подключает сотрудников;
- как сотрудник получает доступ;
- как происходит подтверждение доступа;
- как сотрудники получают персональные пароли;
- как владелец управляет доступами после настройки.

## Файлы

### `index.html`
Стартовый флоу с оплатой. Можно брать за основу для других сценариев и редактировать

### `bot-lpr.html`
Прототип сценария владельца / ЛПР для UX исследования теста настройки совместного доступа к ящику.

Основные сценарии:
- авторизация в боте;
- получение ссылки-приглашения;
- отправка ссылки сотруднику;
- подтверждение или отклонение запроса на доступ;
- просмотр ожидающих подтверждения;
- просмотр подключенных сотрудников;
- сброс пароля сотрудника;
- отключение доступа;
- обновление ссылки-приглашения.

### `bot-employee.html`
Прототип сценария сотрудника / участника для UX исследования теста настройки совместного доступа к ящику.

Основные сценарии:
- авторизация в боте;
- отправка запроса владельцу;
- ожидание подтверждения;
- получение персонального пароля;
- переход к экрану с паролем.

### `password.html`
Экран с персональным паролем сотрудника.

Открывается из сценария `bot-employee.html`.

### `mail.html`
Вспомогательный экран Mail, используемый в прототипе.

### `assets/`
Изображения и другие локальные ресурсы прототипа.

## Запуск

Прототипы представляют собой обычные HTML-файлы и могут открываться локально в браузере или через GitHub Pages.

Основная точка входа:

`index.html`

## Редактирование сценариев

У ботов есть встроенный визуальный редактор.

Чтобы открыть его, добавьте к адресу:

`?edit=1`

Например:

`bot-lpr.html?edit=1`

или

`bot-employee.html?edit=1`

В редакторе можно:
- менять тексты сообщений;
- добавлять и удалять кнопки;
- соединять шаги сценария;
- настраивать автоматические переходы;
- задавать задержку автопереходов;
- смотреть превью сценария;
- скачать обновленный HTML-файл.

Черновики сохраняются локально в браузере отдельно для каждого HTML-файла.

## Важно

Прототипы предназначены для UX-исследования и не являются продуктовой реализацией.

Некоторые переходы и состояния специально упрощены или смоделированы для прохождения исследовательского сценария.
